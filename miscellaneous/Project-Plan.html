AAI-500 3-Week AI/Statistics Project Plan

Academic Project Execution Plan for 3 Cohorts
Submission Deadline: June 21, 2026

Project Objective

Complete an end-to-end AI/statistics academic project involving dataset selection, preprocessing, exploratory analysis, statistical analysis, machine learning model development, report preparation, presentation creation, and final video recording.

Goal: Ensure equal participation among all 3 cohorts in coding, analysis, report writing, PPT preparation, and project presentation.

Team Structure

Cohort Primary Responsibility
Cohort 1 Dataset Understanding & Data Preparation
Cohort 2 Exploratory Analysis & Statistical Analysis
Cohort 3 Model Building, Evaluation & Recommendations

Project Timeline Overview

Week Dates Focus Area
Week 1 May 30 – Jun 5 Dataset Selection, Cleaning & Initial EDA
Week 2 Jun 6 – Jun 12 Statistical Analysis & Model Development
Week 3 Jun 13 – Jun 21 Integration, Report, PPT & Presentation

Week 1 Plan (May 30 – Jun 5)

Goal

Finalize dataset, clean data, and complete initial exploratory analysis.

Cohort 1 Responsibilities

  • Select and understand dataset
  • Define project objective/problem statement
  • Handle missing values, duplicates, and outliers
  • Create preprocessing scripts
  • Prepare Introduction and Dataset Description sections

Cohort 2 Responsibilities

  • Perform exploratory data analysis (EDA)
  • Create charts and visualizations
  • Identify patterns and anomalies
  • Draft exploratory analysis report section

Cohort 3 Responsibilities

  • Research ML/statistical techniques
  • Define evaluation metrics
  • Prepare baseline modeling setup
  • Draft methodology section
Week 1 Review Meeting: Finalize cleaned dataset, approve EDA, and confirm modeling strategy.

Week 2 Plan (Jun 6 – Jun 12)

Goal

Complete statistical analysis and machine learning implementation.

Cohort 1 Responsibilities

  • Support feature engineering
  • Improve preprocessing pipeline
  • Validate cleaned data quality

Cohort 2 Responsibilities

  • Perform statistical testing
  • Conduct regression/correlation analysis
  • Interpret statistical significance
  • Prepare statistical findings section

Cohort 3 Responsibilities

  • Train and compare ML models
  • Evaluate performance metrics
  • Tune parameters if needed
  • Prepare model evaluation section
Week 2 Review Meeting: Finalize statistical analysis, select best-performing model, and validate results.

Week 3 Plan (Jun 13 – Jun 21)

Goal

Finalize report, presentation, and project recording.

Cohort 1 Responsibilities

  • Review report formatting
  • Finalize introduction slides
  • Present project overview and preprocessing

Cohort 2 Responsibilities

  • Validate visualizations and interpretations
  • Cross-check references/citations
  • Present EDA and statistical findings

Cohort 3 Responsibilities

  • Finalize conclusions and recommendations
  • Merge report sections
  • Present ML models and evaluation results

Final Joint Activities

Activity Participants
Report Formatting & Proofreading All Cohorts
PPT Standardization All Cohorts
Video Recording & Practice All Cohorts
Final Submission Verification All Cohorts
